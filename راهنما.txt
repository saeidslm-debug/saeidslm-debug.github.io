راهنمای نصب و استفاده از اپ موبایل «سیستم پایش شاخص‌های کیفی بدنه» (PWA)
================================================================================

این پوشه شامل ۵ فایل است که باید همیشه کنار هم بمانند:
  index.html      → خود برنامه (دقیقاً همون فایل بانک اصلی؛ هیچ شاخص، نقطه،
                    قانون امتیازدهی یا رنگی تغییر نکرده — فقط چند خط برای
                    نصب/آفلاین‌شدن به آن اضافه شده)
  manifest.json   → مشخصات اپ برای «Add to Home Screen»
  sw.js           → Service Worker که کل برنامه را برای کار کاملاً آفلاین کش می‌کند
  icon-192.png / icon-512.png → آیکون اپ (از همان لوگوی بانک اصلی ساخته شده)

چرا فقط دوبار کلیک روی index.html کافی نیست؟
----------------------------------------------
مرورگر Chrome، Service Worker (که آفلاین‌کردن را ممکن می‌کند) و حالت واقعی
«تمام‌صفحه بدون نوار آدرس» را فقط وقتی فعال می‌کند که صفحه از یک آدرس
http:// یا https:// باز شود، نه مستقیم از روی فایل گوشی (file://).
پس فقط یک‌بار لازم است این پوشه «سرو» شود؛ بعدش برای همیشه، حتی بدون
اینترنت، روی گوشی کار می‌کند.

روش ۱ (پیشنهادی — فقط داخل وای‌فای محلی، بدون نیاز به اینترنت واقعی)
----------------------------------------------------------------------
۱. این پوشه را روی همان کامپیوتری که بانک اصلی رویش است نگه دارید.
۲. یک Command Prompt / ترمینال داخل همین پوشه باز کنید و بزنید:
      Windows:  python -m http.server 8000
      (اگر Python نصب نیست: npx serve -l 8000  با Node.js)
۳. آی‌پی همان کامپیوتر را پیدا کنید (در ویندوز با دستور ipconfig — چیزی
   شبیه 192.168.1.23)
۴. گوشی اندروید را به همان وای‌فای کامپیوتر وصل کنید.
۵. در Chrome گوشی به آدرس زیر بروید (به‌جای IP، عدد خودتان را بگذارید):
      http://192.168.1.23:8000/index.html
۶. منوی سه‌نقطه Chrome → «Add to Home screen» / «افزودن به صفحه اصلی».
۷. از این پس آیکون روی صفحه اصلی گوشی است؛ باز شدنش تمام‌صفحه و بدون نوار
   آدرس است و کاملاً آفلاین کار می‌کند — حتی اگر کامپیوتر خاموش یا وای‌فای
   قطع باشد، چون همه‌چیز در حافظهٔ خود گوشی کش شده است.

روش ۲ (اگر یک‌بار اینترنت در دسترس است)
-------------------------------------------
این پوشه را در یک هاست رایگان مثل GitHub Pages آپلود کنید (بدون نیاز به
دستور یا برنامه‌نویسی، فقط از طریق سایت github.com و «Upload files»)،
سپس آدرس عمومی را یک‌بار در Chrome گوشی باز کرده و Add to Home screen
بزنید. بعد از آن دقیقاً مثل روش ۱ کاملاً آفلاین می‌ماند.

نکته: هروقت نسخهٔ جدیدتری از این پوشه گرفتید، عدد داخل CACHE_NAME در
فایل sw.js را عوض کنید (مثلاً به v2) تا گوشی مجبور شود نسخهٔ تازه را
دوباره کش کند.

نحوهٔ کار با اپ (دقیقاً مثل بانک اصلی)
------------------------------------------
ثبت اطلاعات (IQG G&S، TMI، Fitting Gauge با تمام زیرشاخه‌ها، TJC،
ارزشیابی) دقیقاً همان فرم، همان نقاط داده، همان قوانین امتیازدهی و
رنگ‌بندی بانک اصلی است — چون کد کاملاً همان است، فقط برای نصب و آفلاین‌شدن
روی گوشی بسته‌بندی شده. داده‌ها فقط داخل حافظهٔ همان مرورگر گوشی
(localStorage) ذخیره می‌شوند.

انتقال داده از گوشی به بانک اصلی (کامپیوتر)
-------------------------------------------------
۱. در اپ گوشی، دکمهٔ «دریافت فایل پشتیبان / Export» را بزنید (همان دکمهٔ
   Export بانک اصلی).
۲. یک فایل کوچک JSON با نامی مثل quality-data-backup-....json در پوشهٔ
   Download گوشی دانلود می‌شود.
۳. این فایل را از هر راهی که راحت‌اید به کامپیوتر منتقل کنید: تلگرام به
   خودتان، ایمیل، بلوتوث، یا کابل/فلش.
۴. در بانک اصلی روی کامپیوتر، دکمهٔ «Import» را بزنید و همان فایل را
   انتخاب کنید — بانک اصلی همان‌طور که الان هم رفتار می‌کند به‌روز می‌شود.

هشدار مهم
-----------
چون داده‌ها فقط در حافظهٔ مرورگر گوشی ذخیره می‌شوند، اگر کش/داده‌های
Chrome روی گوشی پاک شود، اطلاعات ثبت‌شدهٔ گوشی از بین می‌رود. پس بهتر
است مرتب Export بگیرید و به کامپیوتر منتقل کنید — مخصوصاً قبل از هر
پاک‌سازی مرورگر یا تعویض گوشی.

ورود صوتی اعداد (دکمهٔ میکروفون 🎙️)
--------------------------------------
- وقتی محصول و یکی از شاخص‌های عددی (IQG / TMI / Fitting Gauge / TJC) را
  انتخاب کردید، یک دکمهٔ گرد میکروفون گوشهٔ پایین‌چپ صفحه ظاهر می‌شود.
- روش کار: دکمه را بزنید تا پنل باز شود ← «شروع خواندن» را بزنید ← عددها
  را دقیقاً به همان ترتیبی که در ستون «اندازه» جدول است، یکی‌یکی بخوانید
  (مثلاً: «دو ممیز پنج»، «منفی صفر ممیز صفر پنج»، یا فقط «سه»). بعد از هر
  عدد، خودش به ردیف بعدی می‌رود و ردیف فعلی روی صفحه با رنگ آبی هایلایت
  می‌شود تا گم نشوید.
- دستورهای صوتی: می‌توانید به‌جای عدد بگویید «بعدی» (رد شدن از این
  ردیف)، «قبلی» (برگشتن یک ردیف عقب برای اصلاح)، «پاک کن» (خالی‌کردن
  مقدار ردیف فعلی)، یا «توقف» (پایان ورود صوتی). دکمه‌های معادل همین‌ها
  هم زیر پنل هستند اگر ترجیح می‌دهید با انگشت بزنید.
- نکتهٔ مهم: خودِ تشخیصِ گفتار (تبدیل صدا به متن) از سرویس داخلی کروم
  استفاده می‌کند که برای کار کردن به «اتصال اینترنت لحظه‌ای» نیاز دارد —
  یعنی این یک بخش از برنامه است که برخلاف بقیهٔ اپ، آفلاین کار نمی‌کند.
  اگر گوشی موقع خواندن اعداد اینترنت نداشته باشد، پیغام خطا می‌بینید و
  باید دستی (با تایپ) اعداد را وارد کنید؛ اما ثبت، ذخیره، محاسبهٔ
  نمره/رنگ، و Export/Import مثل همیشه کاملاً آفلاین باقی می‌ماند.
